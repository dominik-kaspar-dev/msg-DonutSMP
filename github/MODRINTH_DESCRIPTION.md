Title: msgDonutSMP

Short: DonutSMP-style private messaging with vanish protection, ignores, and a sleek GUI.

Full:
msgDonutSMP is a lightweight Paper plugin providing private messaging with DonutSMP aesthetics and UX. It includes vanish protection (via PlaceholderAPI), a persistent ignore system with an intuitive skull-head GUI, MiniMessage-configurable formatting, bStats metrics, and permission controls for staff and admins. Designed for servers that want polished, privacy-first messaging without leaking vanished staff.
